// notes for banking system

page 1: login or sign up -> details link to external file

page 2: check balance, deposit, withdraw, transfer, edit / get details, logout

use csv file to store data

users.csv:
username,pin,accountNumber


accounts.csv:
accountNumber,accountType,balance


BankingSystem class:
loadUsers();
loadAccounts();
signUp();
login();
logout();
getBalance();
deposit();
withdraw();
transfer();
editDetails();
saveUsers();
saveAccounts();
generateAccountNumber();


login()
-while username or pin == false
-input username and password/pin
-load users.csv and check if correct
-if correct, store current logged-in user/account
-move to account menu
-else repeat or give option to go back

signup()
-Ask for username
-Check username is not already taken
-Ask for PIN/password
-Ask them to confirm PIN/password
-If they do not match, retry
-Ask for account type: current/savings
-Generate new account number
-Set starting balance to 0
-Save user login details to users.csv
-Save account details to accounts.csv
-Show signup successful message

logout()
-clear current logged-in user
-clear current account number
-return to login/signup page

getBalance()
-check user is logged in
-find their account in accounts.csv / accounts vector
-print current balance

deposit()
-check user is logged in
-ask how much they want to deposit
-check amount is greater than 0
-add amount to balance
-save updated accounts to accounts.csv
-show new balance

withdraw()
-check user is logged in
-ask how much they want to withdraw
-check amount is greater than 0
-check balance is enough
-if enough, subtract amount from balance
-save updated accounts to accounts.csv
-show new balance
-else show insufficient funds

transfer()
-check user is logged in
-ask for target account number
-check target account exists
-ask for amount to transfer
-check amount is greater than 0
-check sender has enough balance
-subtract amount from sender account
-add amount to target account
-save updated accounts to accounts.csv
-show transfer successful message

editDetails()
-check user is logged in
-ask what they want to edit: username or pin
-if username:
    -ask for new username
    -check it is not already taken
    -update username
-if pin:
    -ask for old pin
    -check old pin is correct
    -ask for new pin
    -ask to confirm new pin
    -if they match, update pin
-save updated users to users.csv

loadUsers()
-open users.csv
-skip first row if it has headings
-read each row
-store username, pin and account number in a users vector
-close file

loadAccounts()
-open accounts.csv
-skip first row if it has headings
-read each row
-store account number, account type and balance in accounts vector
-close file

saveUsers()
-open users.csv
-write headings: username,pin,accountNumber
-loop through users vector
-write each user to the file
-close file

saveAccounts()
-open accounts.csv
-write headings: accountNumber,accountType,balance
-loop through accounts vector
-write each account to the file
-close file

generateAccountNumber()
-create random or incrementing account number
-check it does not already exist
-return the new account number

main process:
-create BankingSystem object
-loadUsers()
-loadAccounts()

-while program is running:
    -show page 1 menu:
        1. Login
        2. Sign up
        3. Exit

    -if login:
        -call login()
        -if successful, show page 2 menu

    -if sign up:
        -call signUp()

    -if exit:
        -saveUsers()
        -saveAccounts()
        -end program

account menu process:
-while user is logged in:
    -show menu:
        1. Check balance
        2. Deposit
        3. Withdraw
        4. Transfer
        5. Edit details
        6. Logout

    -call the correct function depending on choice
