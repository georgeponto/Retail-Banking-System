# C++ Banking System
A command-line banking system developed in C++ that simulates fundamental retail banking operations, including account creation, authentication, deposits and withdrawals.
### Project Overview
I developed this project to gain practical experience with C++, having previously programmed primarily in Python. Rather than learning C++ syntax in isolation, I wanted to apply my existing programming knowledge to a functional application while exploring the differences between the two languages.

The project introduced me to concepts such as static typing, variable declarations, control flow, functions and file handling in C++. It also helped me develop my debugging and problem-solving skills in a less familiar programming environment.
### Features
- User registration and login
- Depositing and withdrawing funds
- Account balance management
- Persistent account data using CSV file storage
- Interactive command-line interface
### How It Works
The program allows users to create an account or log in to an existing account. Once authenticated, users can perform basic banking operations through a command-line menu.

Account information is stored in a CSV file, allowing data to persist between executions of the program.
### Technologies Used
- C++ for application logic and user interface
- CSV for persistent data storage
- C++ Standard Library for input/output and file handling
### What I Learned
Coming from a Python background, this project helped me develop a better understanding of:
- Static typing and explicit variable declarations
- The differences between compiled and interpreted programming workflows
- Console input and output using std::cin and std::cout
- Reading and writing files in C++
- Structuring program logic using functions, loops and conditional statements
- Identifying and resolving logic errors through debugging
- Maintaining application state between program executions
The project also reinforced how fundamental programming concepts transfer between languages, despite differences in syntax and implementation.
